# todo-list

Repository for todo-list assignment

### Installation instructions

-Create a new repository and give it the name "todo-list" and description
-do not add a .gitignore or a license
-clone the repo to your local environment

-Bootstrap a new project: npx create-vite@latest --template react .
-install the project dependencies using NPM: npm install

### How to run the development server

-Start the development server with the command: npm run dev
-Open a browser and navigate to http://localhost:5173.
